# Offer Packages

These are early package definitions. They should be used as working offer boundaries, not final public pricing.

## Website Refresh

### Best For

Small businesses with an existing website that needs clearer messaging, stronger trust, better structure, or practical fixes without a full rebuild.

### Includes

- Website review
- Practical improvement recommendations
- Messaging and structure improvements where in scope
- Call to action improvements
- Basic technical and usability checks
- Local visibility recommendations

### Excludes

- Full website rebuild
- Large content rewrite across every page
- Advanced SEO campaign work
- Paid ads
- Custom software or automation
- Ongoing support unless added separately

### Starting Price Direction

Entry-level paid project or audit-based sprint. Final pricing numbers are an open decision.

### Delivery Notes

Keep the scope focused. This should be easy to start, easy to deliver, and useful even if the client does not immediately move into a larger project.

### Client Outcome

The client gets a clearer, more useful website and a practical view of what should be improved next.

## Starter Website

### Best For

New or small businesses that need a credible, simple website and a clear enquiry path.

### Includes

- Lean website structure
- Homepage or compact multi-section page
- Core service information
- Trust signals
- Contact or enquiry path
- Basic responsive setup
- Basic technical hygiene
- Handover guidance

### Excludes

- Large multi-page content strategy
- Advanced local SEO campaign work
- Booking systems unless scoped separately
- Ecommerce
- Custom dashboards or business tools
- Ongoing support unless added separately

### Starting Price Direction

Fixed project fee at a starter level. Final pricing numbers are an open decision.

### Delivery Notes

This should be positioned as a practical foundation, not a cheap throwaway site. It should be clear, credible, and built so it can grow.

### Client Outcome

The client gets a professional website that explains the business, builds trust, and gives prospects a way to enquire.

## Local Growth Website

### Best For

Small local service businesses that need stronger service pages, clearer positioning, and a better foundation for local search and enquiries.

### Includes

- Website structure around core services
- Service pages or service sections
- Local relevance content where appropriate
- Stronger trust and proof sections
- Clear calls to action
- Basic local SEO foundations
- Basic technical hygiene
- Handover guidance

### Excludes

- Guaranteed ranking outcomes
- Ongoing SEO campaign management unless separately scoped
- Paid ads
- Large copywriting projects beyond agreed page scope
- Complex integrations
- Custom software or automation

### Starting Price Direction

Higher fixed project fee than a Starter Website, with pricing based on page count, content needs, and complexity. Final pricing numbers are an open decision.

### Delivery Notes

This is the main website growth offer. It should be sold when a business has clear services, local competition, and a need to be found and trusted.

### Client Outcome

The client gets a stronger website foundation for local visibility, clearer service presentation, and better enquiry flow.

## Automation / Custom Tool Discovery

### Best For

Businesses that already have a clear repeated workflow problem, such as manual admin, tracking work in scattered tools, repeated reporting, or inconsistent client handling.

### Includes

- Workflow discovery
- Problem definition
- Current process mapping
- Opportunity assessment
- Scope recommendation
- Build estimate if a tool or automation is justified

### Excludes

- Full build unless separately quoted
- Open-ended consulting
- Enterprise systems architecture
- Replacing core business software without a strong reason
- Automations without a clear business case

### Starting Price Direction

Paid discovery session or fixed discovery sprint. It may be credited toward a later build if that becomes part of the commercial model. Final pricing numbers are an open decision.

### Delivery Notes

Discovery should protect both sides from vague automation work. The output should make clear whether to build, simplify the existing process, or do nothing yet.

### Client Outcome

The client gets clarity on whether automation or a custom tool is worth building, what it should do, and what it is likely to cost.
