# Project Folder Template

Use this structure for client delivery folders. It is designed to keep project information easy to find without turning the folder into a heavy CRM.

```text
Szymik Digital Clients/
  Client Name - Business Name/
    01 Brief/
    02 Assets/
    03 Copy/
    04 Quote and Invoice/
    05 Preview/
    06 Feedback/
    07 Launch/
    08 Handover/
```

## Root Client Folder

Folder name format:

```text
Client Name - Business Name
```

Example:

```text
Jane Smith - Smith Plumbing
```

The root folder should hold only high-level project files if needed. Most files should sit inside the numbered folders.

## 01 Brief

Use for project understanding and scope context.

Include:

- Discovery notes
- Client questionnaire answers
- Initial enquiry summary
- Scope notes
- Call notes
- Agreed goals
- Important constraints

Suggested file names:

- `brief-client-business-date.md`
- `discovery-notes-client-business-date.md`
- `scope-notes-client-business-date.md`

## 02 Assets

Use for client-supplied or approved assets.

Include:

- Logos
- Brand files
- Photos
- Icons
- PDFs or brochures
- Approved image files
- Access notes where safe and appropriate

Suggested file names:

- `logo-client-business-original.png`
- `photo-service-name-client-business.jpg`
- `brand-assets-client-business-date.zip`

Do not store plain-text passwords in this folder.

## 03 Copy

Use for website text and content drafts.

Include:

- Client-supplied copy
- Edited page copy
- Service descriptions
- Trust content
- Testimonials or reviews approved for use
- Notes on wording that must or must not be used

Suggested file names:

- `homepage-copy-client-business-date.md`
- `service-copy-client-business-date.md`
- `approved-testimonials-client-business-date.md`

## 04 Quote And Invoice

Use for commercial paperwork.

Include:

- Quotes
- Invoices
- Payment notes
- Approved scope documents
- Written approval records where useful

Suggested file names:

- `quote-client-business-date.pdf`
- `invoice-client-business-date.pdf`
- `scope-client-business-date.pdf`
- `approval-client-business-date.pdf`

## 05 Preview

Use for preview links, screenshots, and pre-launch notes.

Include:

- Preview link notes
- Staging links
- Screenshots
- Internal preview checks
- Client preview send dates

Suggested file names:

- `preview-link-client-business-date.md`
- `internal-preview-check-client-business-date.md`
- `preview-screenshot-homepage-date.png`

## 06 Feedback

Use for client review notes and amendment lists.

Include:

- Raw client feedback if useful
- Clean feedback task lists
- Questions for clarification
- Round-by-round amendment notes
- Verification notes

Suggested file names:

- `feedback-round-1.md`
- `feedback-round-2.md`
- `clean-task-list-round-1.md`
- `verification-notes-round-1.md`

## 07 Launch

Use for launch planning and launch checks.

Include:

- Launch checklist
- DNS/domain notes
- Hosting notes
- Go-live notes
- Post-launch checks
- Known issues or follow-up items

Suggested file names:

- `launch-checklist.md`
- `launch-notes-client-business-date.md`
- `post-launch-checks-client-business-date.md`

## 08 Handover

Use for final client handover materials.

Include:

- Handover notes
- Access summary where appropriate
- Editing guidance
- Support options
- Future recommendations
- Testimonial request notes

Suggested file names:

- `handover-notes.md`
- `client-editing-guide-client-business-date.md`
- `support-options-client-business-date.md`
- `future-recommendations-client-business-date.md`

## Naming Guidance

Keep names plain and searchable.

Use:

- Lowercase where practical
- Hyphens between words
- Client or business name where useful
- Date where versions matter
- Clear round numbers for feedback

Recommended examples:

- `quote-client-business-date.pdf`
- `invoice-client-business-date.pdf`
- `feedback-round-1.md`
- `launch-checklist.md`
- `handover-notes.md`

Avoid:

- `final-final-v3.pdf`
- `new doc.docx`
- `stuff.zip`
- Files with unclear owners or dates
