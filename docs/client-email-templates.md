# Hannah Client Comms Pack

This pack gives Hannah copy/paste-ready emails for managing Szymik Digital enquiries, quotes, project updates, previews, launch, and follow-up.

Keep the tone clear, friendly, trustworthy, professional, and simple enough for small local businesses.

## Usage Guide

- Hannah owns client-facing communication.
- Ric owns technical and build decisions.
- Check the tracker status before sending any email.
- Keep one clear next action in every message.
- Do not promise timelines before Ric confirms them.
- Do not start work before client approval and deposit where relevant.
- Keep amendments within the agreed revision round rules.
- Edit each template so it matches the client, project, quote, and tracker notes.
